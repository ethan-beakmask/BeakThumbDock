ThumbDock 操作手冊

適用版本：0.11.6

ThumbDock 是 Windows 的免安裝小工具。它把多個視窗（包含其他虛擬桌面上的視窗）變成即時縮圖，排在螢幕邊緣的「縮圖區」。點一下縮圖，該視窗就會被帶到前面；縮圖會一直留在畫面上，適合同時監看多個視窗，或在很多視窗之間快速切換。

1. 系統需求與取得

  • Windows 11（開發與測試都在 Windows 11 進行；Windows 10 沒有測試過）。
  • 不需要安裝，也不需要系統管理員權限。

發行檔有兩種，功能完全相同：

版本檔案需要另外安裝
內建執行環境（建議）單一個 ThumbDock.exe，約 50 MB不需要
不內建執行環境ThumbDock.exe 加幾個小檔，不到 1 MB.NET 10 Desktop Runtime

把檔案放進一個自己有寫入權限的資料夾（例如 D:\Tools\ThumbDock）再執行。設定檔與記錄檔都放在 exe 旁邊，所以不要放在 C:\Program Files 這類需要管理員權限才能寫入的位置。

2. 第一次啟動

  1. 執行 ThumbDock.exe。螢幕左邊會出現一條縮圖區，裡面有 8 個空的槽位，顯示「等待中　點一下選擇視窗」。
  2. 第一次啟動會跳出 Chrome 的使用提醒（見第 12 節）。看完按「知道了」；不想再看到就勾「以後不顯示」。
  3. 工作列右下角的系統匣會多一個白底黑圓的圖示。

系統匣圖示：

操作結果
點兩下開啟「選擇視窗」
右鍵選單：選擇視窗、設定…、結束

要結束 ThumbDock，請用系統匣右鍵的「結束」。

3. 把視窗放進槽位

開啟「選擇視窗」的方法：點任何一個空的槽位、在系統匣圖示點兩下，或在縮圖區按右鍵選「選擇視窗…」。

「選擇視窗」列出目前所有視窗，一列一個。左邊每一欄代表一個槽位（欄位標題就是槽位編號）。

  • 放進槽位：在該視窗那一列、想要的槽位那一欄勾選。
  • 取消：再點一次同一格。
  • 十字輔助線：滑鼠移到勾選格上時，那一列與那一欄會變色，交叉的那一格顏色較深，方便在視窗和槽位很多時確認沒有勾錯。
  • 清單會自動更新，不需要重新開啟。

其他欄位：

欄位說明
點縮圖時點一下切換：不變 → 最大化 → 填滿操作區。決定點縮圖後該視窗要怎麼擺
原位置視窗被放進槽位時記錄的位置
虛擬桌面視窗在目前桌面或其他桌面
權限顯示「管理員（無法移動）」代表該視窗以系統管理員身分執行（見第 15 節）

「點縮圖時」的三種方式：

方式效果
不變只把視窗帶到前面，位置與大小不變
最大化把視窗最大化（不會蓋到靠邊的縮圖區）
填滿操作區不最大化，把視窗大小調成「螢幕扣掉縮圖區」的範圍

「選擇視窗」上方的功能表：佈局、設定…、檢視、啟動時執行。

4. 使用縮圖

操作結果
點縮圖把該視窗帶到前面，並依「點縮圖時」的設定擺放
把縮圖拖到另一個縮圖上放開兩個縮圖互換位置（編號與快速鍵跟著位置走）
在縮圖上按右鍵選擇視窗…、編輯比對規則…、清除槽位、編輯槽位位置…
在縮圖區空白處按右鍵編輯槽位位置…、選擇視窗…、設定…

目前在最前面的視窗，它的縮圖外框會變成橘色。

如果來源視窗被最小化，縮圖會停止更新（這是 Windows 的限制），槽位上會顯示「已最小化・縮圖暫停（點一下還原）」。可以在設定勾選「來源視窗被最小化時自動還原到最底層」，讓它自動還原但不蓋住其他視窗。

5. 設定視窗

從系統匣右鍵「設定…」或「選擇視窗」的「設定…」開啟。設定視窗可以和「選擇視窗」同時開著；按「確定」才會套用。設定視窗開著的時候，不能切換或管理佈局，也不能編輯槽位位置。

5.1 縮圖區位置

選項說明
左／右／上／下（靠邊）像工作列一樣佔住螢幕的一邊，其他視窗最大化時不會蓋到它
全螢幕（縮圖牆）縮圖蓋滿整個螢幕（見第 6 節）
  • 寬度／高度：靠邊時縮圖區的厚度，單位是 100% 縮放時的像素；螢幕縮放比例較大時會跟著放大。上限是螢幕該方向的 70%。
  • 槽位下方顯示視窗標題：關閉後縮圖會大一點。

5.2 欄 × 列

槽位數量由「欄數 × 列數」決定，最多 100 個。縮圖會排成大小一致、對齊、間距一致的格子。

  • 靠邊的縮圖區比較窄，常見的是 1 欄 × 8 列，或 2 欄 × 8 列。
  • 可以設定間距，也可以勾選「固定縮圖大小」指定每格的寬與高（放不下時等比例縮小）。
  • 只有在這裡的設定（或縮圖區位置、大小）改變時才會重新排列；手動調整過的位置不會被平常的操作覆蓋。
  • 槽位數量達到 24 個以上時會先警告：畫面更新與操作會明顯變慢。
  • 增加槽位：新槽位放在空位，既有槽位不動。
  • 減少槽位：只會刪除沒有綁定的槽位。不夠刪時，先在槽位上按右鍵選「清除槽位」，或勾選「全部解除綁定並重新排列」。

5.3 其他設定

  • 模式：單螢幕或雙螢幕（見第 7 節）。
  • 其他虛擬桌面的視窗：見第 10 節。
  • 快速鍵：見第 9 節。
  • 啟動時呼叫程式：見第 11 節。
  • 語言：見第 14 節。

6. 縮圖牆（全螢幕）

單螢幕時把縮圖區位置選成「全螢幕」，縮圖會蓋滿整個螢幕，成為一面「縮圖牆」。

  • 點縮圖：該視窗顯示在牆的上面。
  • 回到牆：按「顯示／隱藏縮圖區」的快速鍵（預設 Ctrl+Alt+D）。牆已經在最上層時，再按一次會回到上一個視窗。
  • 設定裡的「回到縮圖牆時，把縮圖牆最大化的視窗還原成原本的大小與位置」建議保持勾選，可以避免被蓋住的瀏覽器停止更新。
  • 滑鼠回牆（預設關閉）：在設定勾選後，滑鼠停在螢幕左緣中間約 0.4 秒就會回到牆。拖曳視窗時不會觸發。只對單螢幕的縮圖牆有效。

7. 雙螢幕

在設定把模式改成「雙螢幕」，並指定：

  • 縮圖螢幕：放縮圖區的螢幕。
  • 焦點螢幕：實際操作視窗的螢幕。兩者必須不同。

點縮圖時，原本就在縮圖螢幕上的視窗會被移到焦點螢幕；原本在其他螢幕上的視窗留在原位，只是被帶到前面。

雙螢幕模式下選「全螢幕」，縮圖只會蓋滿縮圖螢幕。如果其中一個螢幕被拔掉，ThumbDock 會暫時改用單螢幕模式，螢幕接回後自動恢復。

8. 編輯槽位位置

在縮圖區按右鍵選「編輯槽位位置…」進入編輯模式，槽位外框會變成藍色虛線。內建的 default 佈局不能編輯，請先「另存為新佈局」。

操作結果
拖曳槽位移動
拖曳槽位的右緣、下緣或右下角調整大小
靠近其他槽位或縮圖區邊界邊緣會自動吸附對齊（同一列、同一欄、相鄰並留間距、同寬同高）
按住 Alt 再拖曳不吸附，逐像素移動
點一下槽位選取（外框變成實線粗框）
選取後按 Del刪除該槽位（沒有確認視窗）
在槽位上按右鍵 →「刪除這個槽位」同上
在空白處按右鍵 →「在這裡新增槽位」新增槽位

編輯完在右鍵選單選「完成編輯」。刪除已綁定視窗的槽位，會連同它的比對規則一起刪除。

9. 快速鍵

在設定視窗的「快速鍵」區塊調整，所有佈局共用。

功能預設
顯示／隱藏縮圖區（縮圖牆時為回到牆）Ctrl+Alt+D
切換到槽位 1–9Alt+Shift+1 ～ Alt+Shift+9（修飾鍵可在設定視窗用三個下拉自訂）

快速鍵被其他程式佔用時，ThumbDock 會通知哪幾個無法註冊。同時開多個 ThumbDock 時，只有最先啟動的那一個有快速鍵。

10. 其他虛擬桌面的視窗

其他虛擬桌面上的視窗一樣可以放進槽位，縮圖一樣會即時更新。點縮圖時有兩種做法，在設定裡選：

選項效果
切換到視窗所在的桌面（switch）Windows 整個切換到那個虛擬桌面
把視窗搬到目前的桌面（pull）桌面不切換，把視窗搬過來

pull 使用 Windows 未公開的介面。遇到不支援的 Windows 版本時，會自動改用 switch。

11. 自動找回視窗與啟動時呼叫程式

11.1 比對規則

把視窗放進槽位時，ThumbDock 會記下一組「比對規則」（行程名稱、視窗類別、標題）。視窗關閉後槽位會顯示「等待中」；同樣的視窗再次出現時，會自動放回原本的槽位。重新開機後也一樣。

規則可以在槽位右鍵的「編輯比對規則…」修改。空白的欄位代表不限制；標題欄位使用正規表示式（Regex）。有多個視窗符合時，綁定第一個。

11.2 啟動時呼叫程式

每個佈局可以有一個「呼叫設定檔」，列出要自動開啟的程式與對應的槽位。ThumbDock 啟動後會依序開啟，並把出現的視窗放進指定槽位。

  1. 在設定勾選「允許 ThumbDock 啟動時依呼叫設定檔呼叫程式」（預設關閉）。
  2. 「選擇視窗」→「啟動時執行」→「編輯呼叫設定檔…」，用表單填寫程式路徑、參數與槽位。
  3. 下次啟動 ThumbDock 時生效；也可以在同一個功能表選「現在呼叫這個佈局的程式」。

槽位已經有視窗時不會重複開啟。詳細格式見 launch-config.md。

12. Chrome 縮圖停格或變黑

Chrome 的視窗被其他視窗完全蓋住，或放在其他虛擬桌面時，Chrome 會自己暫停繪製，縮圖因此停格或變黑。這是 Chrome 的省電機制，不是 ThumbDock 的問題。

解法是用下面任一個參數啟動 Chrome：

--disable-features=CalculateNativeWinOcclusion
--disable-backgrounding-occluded-windows

注意：

  • 參數只對第一個啟動的 Chrome 行程有效。請先完全結束所有 chrome.exe（包含系統匣裡的背景行程），再帶參數啟動。
  • 確認方式：在 Chrome 網址列輸入 chrome://version，「命令列」那一行要看得到參數。
  • Edge 可以用同樣的參數。Brave 實測沒有效果。
  • 停用這個機制會讓 Chrome 多用一些 CPU 與電力。

多個 Chrome 帳號：要讓每個帳號各開一個視窗，需要知道帳號的設定檔資料夾名稱。切到該帳號，在網址列輸入 chrome://version，「設定檔路徑」最後一段（例如 Profile 4）就是名稱，填在啟動參數 --profile-directory="Profile 4"。範本見 launch-sample-chrome-9accounts.json。

13. 佈局

一個「佈局」記錄縮圖區的位置與大小、每個槽位的位置與比對規則。可以為不同的工作情境準備不同的佈局。

在「選擇視窗」的「佈局」功能表：切換佈局、新增空白佈局、另存為新佈局、重新命名、刪除。

  • default 是內建的固定佈局（靠左、寬 200px、8 個槽位排成一欄），不能修改區域設定、編輯槽位位置、重新命名或刪除。要自訂請先「另存為新佈局」。
  • 在設定勾選「切換佈局時，也依該佈局的呼叫設定檔備妥程式」，切換佈局時會自動開啟該佈局需要、但還沒開的程式。

14. 語言

設定視窗最下方的「語言」可以選擇介面語言，重新啟動 ThumbDock 後生效。選「自動」會跟隨 Windows 的語言。

  • 內建：繁體中文、English、日本語、简体中文。
  • 日文與簡體中文是機器翻譯的初稿，沒有經過母語者審閱。發現不通順或錯誤的地方，歡迎到專案頁面回報或直接提交修正。
  • 新增或修正語言不需要重新包裝程式：把語言檔放進 exe 旁的 config\lang\ 再重啟即可。做法見 i18n.md。
  • 不支援由右到左書寫的語言。

15. 命令列參數與同時開多個

參數說明
--layout <名稱>用指定的佈局啟動
--monitor <編號>單螢幕模式，縮圖區放在指定的螢幕（編號在設定視窗看得到）
--no-launch這次不執行呼叫設定檔
--safe安全啟動（見下方）
--help顯示說明

同時開多個：每個實體螢幕最多一個 ThumbDock，每個要使用不同的佈局。

ThumbDock.exe --layout layoutname_1 --monitor 1
ThumbDock.exe --layout layoutname_2 --monitor 2

雙螢幕模式的佈局會佔用全部螢幕，執行期間不能再開第二個。

安全啟動：設定調壞、縮圖區擋住畫面無法操作時，用 ThumbDock.exe --safe 啟動。它會忽略上次的佈局，改用內建的 default 佈局，並且不呼叫任何程式。

16. 公司環境與端點防護軟體

ThumbDock 的工作方式是列舉所有視窗、查詢其他程式的名稱與權限、把其他程式的視窗帶到前面或移動位置。這些動作在部分公司的端點防護軟體（EDR／XDR）看來可能像可疑行為，而被警示或終止。

  • 程式不會連線到網路，不會讀取其他程式的記憶體，也不需要系統管理員權限。
  • 唯一會讀取其他程式資料的地方：在呼叫設定檔的編輯表單選擇 Chrome／Edge 時，會讀取瀏覽器的設定檔清單（帳號名稱），用來顯示下拉選單。不使用這個表單就不會讀取。
  • 如果在公司環境被攔截，請聯絡資訊安全管理人員。對這類行為偵測，程式碼簽章通常沒有幫助；可行的做法是由管理者把該版本發行檔的 SHA256 雜湊加入允許清單。每個版本的雜湊列在發行頁面。
  • 雜湊只對應單一檔案。更新版本或自行從原始碼建置後，雜湊會不同，需要重新申請。
  • 「啟動時呼叫程式」預設關閉，也是基於同樣的考量。

自行確認檔案雜湊（PowerShell）：

Get-FileHash .\ThumbDock.exe -Algorithm SHA256

18. 檔案位置與疑難排解

所有檔案都在 ThumbDock.exe 所在的資料夾：

路徑內容
config\settings.json全域設定（快速鍵、上次使用的佈局等）。同時開多個時，其他實例用 settings.DISPLAYn.json
config\language.txt介面語言
config\layouts\佈局檔
config\launch\呼叫設定檔
config\lang\自行加入或覆蓋的語言檔
logs\thumbdock.log記錄檔，回報問題時請附上

常見問題：

狀況處理
縮圖區太大，擋住畫面無法操作結束程式後用 ThumbDock.exe --safe 啟動

19. 移除

結束 ThumbDock 後，刪除整個資料夾即可。ThumbDock 不會寫入登錄檔，也不會在其他位置留下檔案。
